## 반려 사유 (필수 — 전부 해결 후 r2)
1. **rsc.js 로드 실패 시 빈 화면** — `scripts/externalize-rsc.mjs:38-39`(외부 `<script src>` 삽입). 수정 지시: 페이로드 파일을 못 받으면 정적 HTML이 그대로 보이도록 할 것(빈 화면 금지). 방법은 builder 선택(예: 외부 파일 끝에 로드 완료 표시를 두고, 바로 뒤 인라인 가드가 실패를 감지하면 하이드레이션이 시작되지 않게 막거나 페이로드를 다시 받는 방식 등 — 실제로 동작하는지 검증 필수). 회귀 테스트 추가: e2e 에서 `page.route('**/*.rsc.js*', r => r.abort())` 와 404 두 경우에 H1·본문·FAQ 답변 텍스트가 남아 있고 화면이 비지 않음을 단언. 가드로 해결할 수 없으면 외부화를 되돌리고, LCP 2.0s(QUALITY) vs 2.5s(screen-spec 3·6절) 충돌을 `spec-question` 으로 올릴 것.
2. **Next 출력 형식 변경이 빌드에서 조용히 통과** — `scripts/externalize-rsc.mjs:33`, `:60-73`. 수정 지시: `externalizeAll` 끝에 사후 조건 추가 — (a) 처리 후 `out/**/*.html`(\_next 제외) 어디에도 `self.__next_f` 문자열이 남아 있지 않을 것, (b) App Router HTML 인데 조각을 하나도 못 찾은 파일이 있으면 실패. 둘 중 하나라도 어기면 throw(빌드 실패). `tests/unit/externalize-rsc.test.ts` 에 "매칭 0건"·"일부 조각만 다른 형식(예: `<script nonce=…>self.__next_f.push(…)`)" 두 경우가 실패하는 테스트 추가.
3. **출처가 뒷받침하지 않는 각주** — 가격 범위 문장 10곳: `content/procedures/double-eyelid.mdx:47`, `epicanthoplasty.mdx:45`, `ptosis-correction.mdx:45`, `lower-fat-repositioning.mdx:45`, `rhinoplasty.mdx:45`, `zygoma-reduction.mdx:45`, `square-jaw-reduction.mdx:45`, `thread-lift.mdx:45`, `laser-toning.mdx:45`, `breast-augmentation.mdx:45`, 템플릿 `content/procedures/_template.mdx:48`(이 패턴을 가르침). 무관한 기관 각주가 붙은 조언 문장 예: `thread-lift.mdx:86`(식약처 [2] ← "의료진과 방법을 고르세요"), `double-eyelid.mdx:54`·`:89`(심평원 [3] ← 견적서·묶음 견적 조언), `laser-toning.mdx:52`(심평원 [3] ← 묶음 조건 비교 조언). 수정 지시: (a) 각주 [n] 은 sources[n] 페이지에서 그 문장의 내용을 확인할 수 있을 때만 단다 — 루트가 아니라 해당 내용이 있는 구체 페이지 URL 로 바꾸거나, (b) 확인할 수 없는 문장(특히 가격 범위)에서는 기관 각주를 떼고 근거를 사실대로 적는다(예: 가격 표처럼 "예시 데이터·출처 검증 전" 표기) + `{/* MD-REVIEW */}` 표시. (b)로 섹션 각주 규칙을 못 지키는 경우 린트를 몰래 완화하지 말고 `spec-question` 으로 올릴 것. 10편 전체를 같은 기준으로 다시 점검하고, 고친 각주 목록(파일:줄 → 출처 페이지)을 로그에 남길 것.
