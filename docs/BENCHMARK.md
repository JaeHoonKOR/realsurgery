### 1-3 밀도 규칙 — `check-density.mjs` vs `bench-measure.mjs`

| 항목 | `scripts/check-density.mjs` | `bench-measure.mjs --rule bench` (이 문서의 값) |
| --- | --- | --- |
| 선택자 | `img, svg, canvas, video, [data-visual]` | 왼쪽 + `picture` + CSS `background-image: url()` 요소(div·span·a·li·section·button·i) |
| 크기 | ≥ 24×24px | 같음 |
| 가시성 | 필터 없음 | `visibility:hidden`·`display:none`·`opacity:0` 제외(배경 이미지 요소는 크기만) |
| 중첩 | svg 안 svg, picture 안 img도 각각 셈 | 바깥 svg 1개, picture 안 img 제외 |
| 대기·지연 로딩 | `networkidle` + 500ms, 스크롤 없음 | `load` + 3,500ms, 500px씩 끝까지 스크롤 후 600ms |
| 내부 스크롤 컨테이너 | 없음(문서 높이만) | 가장 큰 `overflow-y:auto/scroll` 컨테이너 높이 포함 |
| 폭 | 375×667만 | 375(667px 구간)·1280(800px 구간) |
