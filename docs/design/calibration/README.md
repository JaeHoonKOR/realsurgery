# 사용자 판정 예시

evaluator 점수를 사용자 취향에 맞추는 예시 모음이다. `/report`가 하루 끝에 사용자 판정을 받아 여기에 쌓는다.

## 파일 하나 = 판정 하나
파일 이름 `YYYY-MM-DD-<기능id>.md`. 스크린샷은 같은 이름의 `.png`로 옆에 둔다(사람이 판정한 화면만 커밋한다).

```
- 기능: F-003 메인 첫 화면
- 스크린샷: 2026-11-10-F-003-375.png, 2026-11-10-F-003-1280.png
- evaluator 점수: 디자인 완성도 4 · 독창성 3 · 만듦새 4
- 사용자 판정: 별로 (디자인 완성도 2)
- 이유: 카드가 전부 같은 크기라 무엇부터 봐야 할지 모르겠다
```

evaluator와 사용자가 2점 이상 어긋난 판정이 가장 중요한 예시다. 지우지 않는다.
