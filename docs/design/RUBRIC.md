# 화면 평가 기준

evaluator가 기능마다 쓰고, builder가 만들 때 참고한다. Anthropic의 프런트엔드 평가 기준 4개([Harness design for long-running apps](https://www.anthropic.com/engineering/harness-design-long-running-apps))에 이 서비스의 "신뢰"와 "공유" 기준을 더했다. 서비스 목표는 무료로 많은 사람이 쓰고 퍼뜨리는 것이다(`docs/product/BRIEF.md`).
점수는 사용자 판정 예시(`calibration/`)에 맞춘다. 예시와 점수가 어긋나면 예시가 옳다.

| 기준 | 묻는 것 | 하한 |
| --- | --- | --- |
| 기능 | 기능의 steps가 375·1280 둘 다에서 끝까지 되는가. 카드·목록 항목은 눌리는가. 콘솔 error 0, 깨진 링크 0 | **5/5** (steps 하나라도 실패 = FAIL) |
| 신뢰 | 금지 표현 0, 시술 정보에 출처, 가격은 범위+출처+조사일, 지어낸 숫자 0. 처음 온 사람이 믿을 만한가 | **5/5** (위반 1건 = FAIL) |
| 디자인 완성도 | 화면이 하나의 분위기로 묶여 있는가. 무엇을 먼저 봐야 할지 위계가 분명한가 | 3/5 |
| 독창성 | 템플릿·라이브러리 기본값·흔한 AI 패턴(보라 그라디언트, 아이콘 3개 나열, 똑같은 카드 그리드 반복)이 아니라 이 서비스를 위해 내린 결정이 보이는가 | 3/5 |
| 만듦새 | 타이포 위계, 간격 리듬, 색 대비, 터치 영역 44px, 글자 잘림·겹침 없음 | 4/5 |
| 공유 | 이 화면을 본 사람이 친구에게 보낼 이유(결과·비교·체크리스트처럼 보낼 만한 것)가 있는가. 공유 미리보기(OG 제목·설명·이미지)가 화면 내용과 맞고 이미지가 열리는가. 공유 버튼이 있으면 실제로 동작하는가 | 3/5. OG 메타 누락·이미지 404 = 1점. 폼 단계처럼 공유 대상이 아닌 화면은 "해당 없음" |

## 점수 기준
- 5: 경쟁 서비스(강남언니·바비톡)보다 낫다고 말할 수 있다.
- 4: 경쟁 서비스와 같은 수준이다.
- 3: 쓸 만하지만 특징이 없다.
- 2: 눈에 띄는 문제가 있다.
- 1: 깨졌거나 비어 있다.

디자인 완성도·독창성·공유는 하한이 낮은 대신 가장 중요하게 본다.

## 하한과 목표
- **하한**(위 표)은 기능 통과 조건이다. 하나라도 미달이면 FAIL.
- **목표**는 category가 `screen`인 기능에만 있다: 디자인 완성도 ≥ 4 **그리고** 독창성 ≥ 4(경쟁 서비스 수준 이상). 기능이 통과한 뒤 `/cycle` 5절 디자인 반복(최대 5라운드)이 목표까지 끌어올린다. 목표에 못 미쳐도 기능은 통과지만, progress에 "디자인 목표 미달"로 남고 `/report`에서 사용자 판정을 먼저 받는다.
- 디자인 라운드에서 evaluator는 같은 화면에 같은 점수를 준다. 라운드 수는 점수를 올리는 이유가 아니다.
