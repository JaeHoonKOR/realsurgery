## 2. 원칙
1. **요건 1개 = 실데이터 증거 ≥ 1 + 배포 URL 위의 화면 위치 1곳.** 예: AEO = D3 시트 + P-03 "AI 답변용 요약" 박스. 화면 위치가 없는 요건은 미완.
2. **3층 구조**: 커버(D8, A4 1쪽, 본문 ≤ 400자) → 제출물 PDF(각 A4 1쪽) → 원본(CSV·캡처·URL). 상위 층의 숫자는 모두 하위 층으로 링크된다.
3. **숫자 3요소**: 모든 숫자에 기간·출처·캡처일. 목표 미달은 "미달"과 실측값으로, 표본 5건 미만 비율은 "표본 부족"으로 쓴다. 예: "구글 색인 9 / 목표 20 (서치콘솔, 2026-11-01~11-23, 캡처 2026-11-23) — 미달".
4. **단일 장부, 경로 1개**: 숫자·증거 원본은 `reports/**`뿐이다. `scripts/build-metrics.mjs`가 `reports/**` → `reports/metrics.json` 1개를 만들고, `/insights`(D7)와 `scripts/deliverable-pdf.mjs`(PDF)는 이 파일만 읽는다. `docs/deliverables/*.md`는 문안 템플릿이며 숫자 직접 입력 0개(`{{metric_id}}` 자리표시자만). 리드 수의 원본은 `leads.csv`의 UTM 마지막 클릭 귀속이고, 플랫폼 보고 수치는 별도 열에 차이와 함께 적는다.
5. **법무 경계 우선(95 > 90)**: 효과 보장 문구·전후 사진·AggregateRating·개인정보(이름·전화·이메일) 0건. 평점 대신 3-10의 신뢰 요소 5개로 증명한다. 비용이 드는 항목은 `needs-approval` 승인 전 집행·구매 0원.
