## 3. 반려 사유
1. **RealSelf SSR 값(B-44 14·B-30 67%·B-29 RealSelf 3)이 문서가 선언한 측정 코드로 재현되지 않고 raw도 없다** — `docs/BENCHMARK.md` 1절 "측정 코드"·"정적 HTML 보조(B)" 행, 2-2 RealSelf 열 "출처·각주"·"인터랙션" 행, 4-4/4-5 B-29·B-30, 4-7 B-44. r1 반려 4(측정 재현 불가, 실제 코드가 gitignored `.playwright-mcp/`에 있음)와 같은 유형.
   - 1절은 "측정 코드 = `scripts/bench-measure.mjs`(경쟁사·우리 공용)"라고 쓰지만, `--ssr`의 `ssrOne`(174~193행)은 ld·h1·a[href]·viewport·sig(src·upd·faq·review·won·man·sup)만 낸다. `[aria-expanded]` 수, 참고문헌 수, PubMed/DOI 링크 수는 세지 않는다.
   - `aria-expanded` SSR 수(2-1 8·2-2 14·2-3 36)는 gitignored `.playwright-mcp/ssr.mjs` 23행에서만 나온다. r3의 참고문헌 3·PMID 2/3은 저장 안 된 일회성 분석이고 HTML도 지웠다. `raw/r2-realself-ssr.json`에는 셋 다 없다.
   - 1절 B 행은 "JSON-LD·h1·a[href]·viewport·텍스트 신호만 센다"라고 적어서 이 세 값이 범위 밖이다. "RealSelf B-29·B-30·B-44는 SSR HTML 기준이고 렌더 후 개수는 확인 못 함"은 작성자 로그(남은 리스크 2)에만 있고 1절에는 없다.
   - 이 셋 중 B-44 14가 실제 목표(≥ 14)를 정하고, 그 목표 때문에 P-03 본문 H2 5개를 아코디언 버튼으로 바꾸게 된다. 그래서 값이 맞는지 다시 확인할 수 있어야 한다. `aria-expanded=` 정규식은 헤더 메뉴 버튼도 함께 세는데, 지금은 "전부 accordion trigger"라는 주장을 확인할 raw가 없다.
   - **고칠 방법**:
     (a) `ssrOne`에 `ariaExpanded`(`aria-expanded=` 속성 수, 가능하면 `<button`에 붙은 것만), `refLinks: { pubmed, pmc, ncbiBook, doi }`(href 호스트·경로 패턴 수)를 추가하고 `--out` 1줄 요약에 출력한다.
     (b) RealSelf 시술 상세를 `--ssr --out reports/benchmark/raw/r3-realself-ssr.json`으로 1회 받는다(robots 허용 경로, 요청 1회, 0절 열람 수 갱신). 2-2·B-29·B-30·B-44 칸에 raw 경로를 적는다. 값이 14·3·2/3와 다르면 R-최고값대로 B-44 목표와 6절 P-03 6번을 다시 맞춘다.
     (c) 1절 "정적 HTML 보조(B)" 행의 센 지표 목록에 `[aria-expanded]`·참고문헌 링크 수를 넣고, "RealSelf 값(B-21·B-22·B-29·B-30·B-44, 2-1·2-3 aria-expanded)은 SSR HTML 기준이고 렌더 후 개수는 확인하지 못함" 1줄을 넣는다.
