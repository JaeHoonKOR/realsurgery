## 가정 (무인 모드, 가장 단순한 해석)
- 가정: **아직 없는 화면으로 가는 링크는 노출하지 않는다.** GNB 4개는 모두 P1 화면이고, CTA 대상(P-06)은 T-101, 검색 대상(P-03)은 T-103, 약관은 T-108이다. 그대로 링크하면 QUALITY 1절 "깨진 내부 링크 0, 모든 CTA가 실제 경로로 이동"을 어기고 배포된다. 그래서 `lib/built-routes.ts`가 빌드 때 `app/`의 page 파일을 훑어 실제로 있는 경로만 링크로 노출한다. 해당 화면 작업이 page를 추가하면 자동으로 나타난다. **지금 배포 화면(홈)에는 로고·동의 배너·푸터(면책·운영 시간·사업자 정보)만 보인다.**
- 가정: 전체 컴포넌트 검증은 개발 서버 전용 미리보기 `/preview/`(`app/(site)/preview/page.preview.tsx`, `RS_PREVIEW=1`일 때만 pageExtensions에 포함)에서 한다. 정적 export(out/)에는 들어가지 않는다(`ls out` 확인). 미리보기에서는 모든 경로를 있는 것으로 본다.
- 가정: "스크롤 시 축소 고정" = 상단 바(로고·CTA)는 sticky로 고정하고, 모바일 2번째 줄(검색·GNB)은 스크롤과 함께 사라진다. 데스크톱은 1줄 고정이고 스크롤하면 그림자가 생긴다(스크롤 연동 CSS). 레이아웃 높이가 바뀌지 않으므로 CLS는 0이다(e2e로 측정).
- 가정: 하단 바의 전화·카톡은 `clinic.is_partner && 값 있음`일 때만 보인다(8절 폴백). P-03(시술)에는 병원이 없으므로 상담 버튼만 남는다.
- 가정: 동의 배너는 버튼 2개(선택 저장 / 모두 동의)다. 토글 기본값이 꺼짐이므로 "선택 저장"을 누르면 1탭으로 거부된다. 토글 매핑: 방문 통계 → analytics_storage, 광고 성과 측정 → ad_storage·ad_user_data·ad_personalization.
- 가정: Consent Mode 기본값은 `<head>` 인라인 스크립트가 dataLayer에 Arguments 객체로 push한다(GTM이 consent 명령으로 읽는 표준 형식). 태그 로드는 하지 않는다. check-out의 `gtag(` 검사와 별개로 단위 테스트에서 태그 로드 문자열이 없음을 확인했다.
- 가정: 병원 주소는 동 단위까지만 쓴다(예: "서울특별시 강남구 신사동"). 가상 병원이 실존 건물 번지를 가리키지 않도록 하기 위해서다. 좌표는 동 중심 근사값이다.
- 가정: 시술 ID는 ASCII(`double-eyelid`, 이미지 파일명과 같은 키), slug는 한글(2절 URL 규칙)이다.

## 기타 기록
- `backlog/sources.md` 시드 URL 상태: prskorea.co.kr는 실제로 "대한성형외과의사회"다(학회는 plasticsurgery.or.kr). prs.or.kr는 자가 서명 인증서, hira.or.kr/npay는 연결 시간 초과, snuh.org/health/nMedInfo는 404다. content lane이 참고할 것(파일은 수정하지 않음).
- 액션 버전 확인 중 `gh api`로 다른 공개 저장소(actions/*, pnpm/action-setup)의 릴리스를 node 스크립트에서 읽었다. 그 뒤 직접 `gh api`를 호출했을 때 guard가 "다른 저장소 대상"으로 막았고, 그 이후로는 우회하지 않았다. 읽기 전용 조회였지만 guard 정책상 앞으로는 WebFetch 등으로 대체해야 한다.
- 이 로그의 가격·회복기간 수치는 공개 시세 검색과 일반 의학 정보 수준이다. 시술별 3개 이상 출처 검증은 content lane(T-300~)이 MDX를 작성할 때 다시 하고 시드를 교체한다.
