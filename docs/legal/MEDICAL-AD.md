## 2. 사이트의 법적 성격
우리는 의료기관이 아니므로 **의료광고를 만들지 않는다**. 사이트는 시술 정보와 가격 범위를 보여주는 정보 서비스로 설계한다.

| 영역 | 위험 | 지킬 것 |
| --- | --- | --- |
| 시술 정보 | 낮음 | 본문에 병원명 0개. 출처 각주 |
| 병원 정보 | 중간 | 공개 사실(명칭·지역·주소·진료과목·공개 가격 범위)만. "추천·제휴·인기" 0개. 대가 여부로 노출 순서·문구가 달라지지 않음 |
| 가격 비교 | 중간 | 범위 + 출처 + 조사일. "더 저렴" 같은 평가어 0개 |
| 상담 연결 | **높음 (L3)** | 리드·예약·내원 수에 연동된 대가 0원. 사용자 요금 0원. 병원 전달은 제3자 제공 동의 + 제휴 병원만 |
| 병원 광고 게재 | 해당 | 병원이 심의받은 원고 그대로 + "광고" 라벨 + 심의번호. 월 정액만 |

## 4. 사용자 참여 기능의 경계 (콘텐츠 정의 때 다시 확인)
- 이용자 후기·경험 게시판: 특정 병원·의사와 연결되면 치료경험담 광고(L1)로 볼 위험. 병원명 없는 질문·답변도 운영 방식에 따라 다르므로 D-4 변호사 검토 항목.
- 개인 기록(관심 시술 저장, 회복 일정): 건강 관련 정보라 서버 저장 시 민감정보 별도 동의. 브라우저에만 저장하면 수집이 아니다.
- 상담 신청 폼: 관심 시술 = 민감정보 별도 동의. 체크박스 기본 해제. 만 14세 미만 차단.
